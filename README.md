

# Rally Rivals

Unity Netcode for GameObjects를 활용한 실시간 1:1 멀티플레이 핑퐁 게임입니다.

기본 핑퐁 규칙에 랜덤 아이템과 시간에 따른 공 속도 증가 요소를 추가했습니다.

- **개발 형태:** 개인 프로젝트
- **개발 기간:** 2026.02 ~ 2026.10
- **핵심 개발 기간:** 약 1개월, 이후 기능 개선 및 폴리싱

## 주요 기능

- Unity Relay를 이용한 인터넷 멀티플레이
- 방 코드 기반 방 생성·참가 및 Lobby Service를 이용한 랜덤 매칭
- 서버 권한 기반 공 물리·점수 판정
- 플레이어·공·아이템 상태 동기화
- 랜덤 아이템 생성 및 미획득 아이템 자동 제거
- 패들 충돌 위치에 따른 공 반사 방향 변화
- 시간에 따른 공 속도 증가
- 게임 재시작 투표 및 로비 복귀
- BGM·효과음·패들 충돌 이펙트

## 기술 스택

| 구분 | 사용 기술 |
|---|---|
| 엔진 | Unity 6.3 LTS (`6000.3.8f1`) |
| 언어 | C# |
| 네트워크 | Netcode for GameObjects `2.8.0`, Unity Transport |
| 온라인 서비스 | Unity Lobby, Unity Relay |
| 렌더링 | Universal Render Pipeline |

## 핵심 구현

### 멀티플레이 연결

호스트가 Relay 참가 코드와 Lobby를 생성하고, 클라이언트는 방 코드를 입력하거나 랜덤 매칭으로 참가합니다.

방 생성 시 랜덤 매칭 허용 여부를 선택할 수 있습니다. 참가 가능한 방이 없으면 새로운 방을 자동으로 생성하지 않고, 사용자가 취소할 때까지 일정 주기로 방을 탐색합니다.

### 네트워크 동기화

공의 이동과 충돌, 득점, 아이템 생성 등 주요 게임 로직은 서버에서 처리합니다.

- **점수·게임 상태:** `NetworkVariable`로 동기화
- **효과음·충돌 이펙트:** 일회성 연출을 RPC로 전달
- **플레이어 이동:** 각 클라이언트가 자신의 플레이어를 조작하고 `NetworkTransform`으로 이동 결과 동기화

### 공 물리

공이 패들에 충돌한 위치를 기준으로 반사 방향을 계산합니다. 플레이어는 패들의 위치를 조절해 공을 다른 방향으로 보낼 수 있습니다.

경기 시간이 지날수록 공의 기본 속도가 증가하며, 속도 증가 아이템이 적용되더라도 지정된 최대 속도를 넘지 않도록 제한했습니다.

### 아이템 시스템

서버에서 아이템 종류와 위치를 무작위로 결정하고, `NetworkObject`를 통해 네트워크에 생성합니다.

| 아이템 | 효과 |
|---|---|
| 플레이어 이동속도 증가 | 패들의 이동속도 증가 |
| 공 속도 증가 | 공의 이동속도 증가 |
| 공 크기 감소 | 공의 크기 감소 |

일정 시간 동안 획득되지 않은 아이템은 서버에서 제거합니다. 득점 시에는 남아 있는 아이템과 적용 중인 효과를 초기화하고 다음 라운드를 시작합니다.

### 게임 종료 및 재시작

목표 점수에 도달하면 경기를 종료하고 승패 결과를 표시합니다.

두 플레이어가 모두 재시작에 동의하면 점수와 아이템 효과를 초기화하고 새로운 경기를 시작합니다. 경기 종료 후에는 두 플레이어가 함께 로비로 돌아갈 수도 있습니다.

## 문제 해결

### 아이템 스폰 타이머 중복

**문제:** 득점 후 아이템 스폰 타이머를 초기화했지만, 이전 코루틴이 남아 아이템이 예상보다 빠르게 생성됐습니다.

**해결:** 실행 중인 코루틴을 변수로 관리하도록 변경했습니다. 라운드 초기화 시 기존 코루틴을 종료한 뒤 하나의 스폰 루프만 다시 시작하도록 수정했습니다.

### 미획득 아이템으로 인한 다음 스폰 지연

**문제:** 공의 이동 경로에서 벗어난 아이템이 오랫동안 남아 다음 아이템이 생성되지 않았습니다.

**해결:** 생성된 아이템을 추적하고, 제한 시간이 지나도 획득되지 않으면 서버에서 `Despawn()`하도록 변경했습니다. 제거 후에는 다음 스폰 타이머를 시작합니다.

## 실행 방법

1. Unity `6000.3.8f1` 버전으로 프로젝트를 엽니다.
2. Unity Services 프로젝트를 연결하고 Lobby 및 Relay를 활성화합니다.
3. `Assets/Scenes/LobbyScene.unity` 씬을 엽니다.
4. Multiplayer Play Mode 또는 별도 빌드를 이용해 호스트와 클라이언트를 실행합니다.
5. 한쪽에서 방을 생성하고, 다른 쪽에서 방 코드를 입력해 참가합니다. 랜덤 매칭을 사용하려면 호스트가 방 생성 시 랜덤 매칭을 허용해야 합니다.

## 개발 과정 및 AI 활용

개인 프로젝트로 게임 기능을 구성하고, Unity 씬·프리팹 구성과 Inspector 연결, 호스트·클라이언트 테스트를 수행했습니다. 플레이 중 문제를 재현하고 수정 사항을 적용한 뒤 동작을 확인했습니다.
NGO·Lobby·Relay 기반 네트워크 기능의 코드 작성과 RPC·동기화 오류 분석에는 생성형 AI를 활용했습니다. AI가 제안한 코드와 해결 방법을 프로젝트에 통합하고, 실제 실행 환경에서 검증했습니다.
